# AI Literacy Periodic Table: first version (AIAD strands)

Superseded on 19 November 2026. Kept for reference.

This version re-sorted the table into six families built on the AI Awareness Day themes (How AI works, Safe, Smart,
Creative, Responsible, Future), with 105 newly written elements, each with a definition and a "Talk about it" question,
coloured in the AIAD strand colours.

The live page now uses the original Periodic Table of AI: its 120 terms, seven families, layout and family colours,
in the site's own styling.
